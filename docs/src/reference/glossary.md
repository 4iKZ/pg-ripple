# Glossary

The canonical project glossary is maintained at the repository root so that contributors, users, tests, and documentation share one vocabulary.

[Read the shared pg_ripple glossary](https://github.com/trickle-labs/pg-ripple/blob/main/GLOSSARY.md)

The glossary explains the terms that shape pg_ripple's design, including RDF concepts, dictionary encoding, VP storage, SPARQL planning, Datalog inference, SHACL validation, CDC, and the HTTP companion service.
